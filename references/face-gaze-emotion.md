# Faces, Gaze and Emotion

## Face vs no-face

A face is a tool, not a requirement.

Use a face when human reaction, identity, emotion, or trust is part of the story.

Prefer no face when:

- the object/result is more visually powerful
- a face would add generic emotion without information
- the niche convention favors object-led communication

Test face vs no-face when uncertain.

## Expression

Choose an expression that matches the actual promise:

- surprise
- curiosity
- concern
- joy
- anger
- concentration
- disbelief
- relief

Avoid generic exaggerated emotion disconnected from the video.

## Gaze

Use gaze direction intentionally.

Direct gaze can create personal connection.

Indirect gaze can guide the viewer toward:

- an object
- a text hook
- a conflict
- a result

Avoid placing important faces where platform UI or timestamps can interfere.

## Face placement

Test left, center, and right placements when useful.

Do not assume one universal best position.

## Consistency

If the creator is recurring, preserve recognizable identity and coherent lighting across thumbnails.

When using AI identity tools, only use faces/likenesses with appropriate permission and avoid copying another creator's identity.
