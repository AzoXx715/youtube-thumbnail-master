# Object Isolation vs Background Removal

## Decision rule

Keep context when it explains the story.

Remove context when it competes with the story.

## Keep the scene when

- location is part of the promise
- environment identifies the topic
- the object needs context
- the setting is itself a hook

Use depth, blur, contrast control, and selective simplification to keep the scene subordinate.

## Remove the background when

- it adds little meaning
- it creates clutter
- text needs clean contrast
- branding needs repeatable backgrounds
- the subject needs maximum dominance

## Finishing

A subtle outline or soft shadow can improve separation of a cutout. Avoid excessive outlines and effects.

## Mobile test

At small size, ask:

- does the subject read instantly?
- does the context add meaning?
- does the background create an accidental focal point?
- is text easier or harder to read?

Choose the version that improves communication, not the version that is aesthetically simpler by default.

## Evidence caution

Reported CTR differences from isolated case studies should be treated as examples, not universal causal rules.
