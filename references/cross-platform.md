# Cross-Platform Thumbnail Adaptation

## Principle

Create one strong visual concept, then adapt the composition for each platform.

Do not blindly resize one file.

## Master

Start from a high-quality 16:9 master when YouTube is the primary destination.

Keep critical information inside a robust central region so it survives crops.

## Test crops

When relevant, preview:

- 16:9
- 4:5
- 1:1
- 9:16

## Platform-specific adaptation

Account for:

- crop behavior
- timestamps
- interface overlays
- safe zones
- feed/grid scale
- text readability

Reposition elements rather than simply shrinking them.

## Rule

The visual hierarchy must survive every crop.

If it cannot, create a platform-specific composition derived from the same concept.

## Small-size test

Check the important content at approximately 120–160px wide or an equivalent small preview. Tiny details should never carry the main message.
