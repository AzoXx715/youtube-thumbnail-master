# Trends and Competitive Patterns

## Trend research

Use trend data to identify:

- rising topics
- recurring visual motifs
- seasonal demand
- emerging color/composition patterns
- changing audience language

Use trends to generate hypotheses, not to blindly copy current aesthetics.

## Competitor sampling

Prefer recent comparable uploads.

For each competitor inspect:

- topic
- title formula
- thumbnail structure
- subject scale
- face/no-face
- text/no-text
- color
- contrast
- emotional framing
- visual metaphor
- upload timing
- observed performance relative to their baseline

## Outliers

An outlier is more informative when it:

- materially exceeds the channel's normal performance
- is comparable in format/topic
- is not obviously driven by an external event alone

Repeated patterns across several outliers are stronger evidence than one viral video.

## What to extract

Extract principles such as:

- shorter hook
- tighter crop
- single object
- stronger contrast
- clearer before/after
- larger face
- no-text composition
- stronger result visualization

Then create original variants for the user's channel.

## Avoid trend fatigue

If every thumbnail uses the same:

- red arrow
- shocked face
- giant text
- glow
- circle

the visual language becomes less distinctive.

Use trends selectively and preserve channel identity.
