# Audience and Context

## Core principle

There is no universally optimal thumbnail.

The same visual can perform differently by:

- niche
- audience intent
- traffic source
- device
- geography/language
- video format
- topic maturity
- channel familiarity

## Audience intent

Classify the viewer intent when possible:

- search/problem solving
- discovery/browse
- returning subscriber
- entertainment
- comparison
- purchase/review
- news/current event
- education
- inspiration

Design the thumbnail to answer the viewer's immediate question while preserving curiosity.

## Traffic source

Interpret performance separately for:

- Home/Browse
- Suggested
- Search
- External
- Notifications

Do not compare raw CTR across sources as if they were equivalent.

## Search packaging

For search-led videos:

- match the title and thumbnail to the searcher's intent
- make the subject obvious
- avoid cryptic visuals that require context
- keep the hook complementary to the title

## Returning viewers

For familiar audiences, recognizable faces, recurring visual language, and brand cues may carry more value.

## New viewers

For unfamiliar audiences, topic clarity and immediate visual comprehension become especially important.

## Device

Design mobile-first, but verify desktop presentation too.

## Geography and language

When localization matters:

- preserve the core visual concept
- adapt text naturally to the target language
- account for text expansion/contraction
- check cultural color and imagery associations
- create regional variants only when there is a reason to test them

Never assume one country's visual conventions apply universally.
