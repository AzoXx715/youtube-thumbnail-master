# Visual Hierarchy

## Primary principle

A thumbnail is an attention-routing system.

The viewer should not have to search for the subject.

## Preferred hierarchy

1. Primary subject
2. Hook/text
3. Supporting visual
4. Background
5. Atmosphere

## Hierarchy budget

Use a deliberate budget before generating:

- 1 dominant focal point
- 1 secondary focal point at most
- 1 short text block
- 0–2 meaningful contextual cues
- atmosphere only when subordinate

Do not compensate for a weak concept by adding more objects.

## Scale

The primary subject should generally be the largest meaningful element.

A logo, franchise title, decorative object, or background landmark should not become larger or more contrasty than the actual story subject unless it is the story.

If the subject feels too small, remove competing elements before shrinking the entire composition.

## Attention signals

- face
- eyes
- size
- brightness
- local contrast
- sharpness
- saturation
- isolation
- directional lines
- unusual shapes

## Attention parasites

An element is suspicious when it receives more attention than its narrative importance.

Examples:

- oversized logo
- bright background light
- random object
- decorative text
- high-contrast background detail
- secondary face
- unnecessary map/building detail

## Semantic hierarchy

Visual hierarchy is not only about attention. It also controls meaning.

Check:

- which person is associated with which country/side
- which object is associated with which event
- whether arrows point to the intended subject
- whether flags, logos, and maps are spatially coherent
- whether the composition accidentally implies the opposite of the story

A semantically incorrect but visually attractive composition is still a failed thumbnail.

## Correction methods

Redirect attention by changing:

- subject scale
- contrast
- brightness
- sharpness
- crop
- depth
- background complexity
- text weight
- object size
- positional relationships

## Background simplification

When a background contains many meaningful objects, do not automatically preserve all of them.

Ask whether each object:

1. establishes necessary context,
2. supports the hook,
3. creates useful contrast/depth.

If not, remove or strongly subordinate it.

Prefer one clear environment over a collage of environments unless the collage itself is the story.

## Subtraction pass

Before delivery:

- remove one unnecessary object
- remove one unnecessary effect
- enlarge the hero subject if possible
- enlarge the hook if necessary
- check for accidental focal points

Prefer subtraction to global shrinking.

## Mobile

At small size, the viewer should still identify:

- subject
- emotional tone
- core event
- text when used

If several elements merge into noise, simplify.

## Simplicity rule

Do not fill empty space just because it exists.

Negative space is useful when it improves hierarchy.
