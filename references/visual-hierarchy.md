# Visual Hierarchy

## Primary principle

A thumbnail is an attention-routing system.

The viewer should not have to search for the subject.

## Preferred hierarchy

1. Primary subject
2. Hook/text
3. Supporting visual
4. Background

## Signals that attract attention

- face
- eyes
- size
- brightness
- local contrast
- sharpness
- saturation
- isolation
- directional lines
- unusual shapes

## Attention parasites

An element is suspicious when it receives more attention than its narrative importance.

Examples:

- oversized logo
- bright background light
- random object
- decorative text
- high-contrast background detail

## Correction methods

Redirect attention by changing:

- subject scale
- contrast
- brightness
- sharpness
- crop
- depth
- background complexity
- text weight
- object size
- positional relationships

## Simplicity rule

Do not fill empty space just because it exists.

Negative space is useful when it improves hierarchy.
