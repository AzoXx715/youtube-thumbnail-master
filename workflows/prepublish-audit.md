# Workflow: Pre-Publish Audit

Run this final gate:

## Communication
- one dominant idea
- one clear focal point
- curiosity without confusion
- title and thumbnail complement each other

## Visual
- subject clearly separated
- background subordinate
- contrast intentional
- no accidental hotspot
- text readable
- face/expression coherent when used

## Mobile
- test approximately 120–160px equivalent
- test real phone when possible
- check small-screen crop
- check bottom-right timestamp/UI area

## Brand
- compare against recent uploads
- consistent visual language
- enough variation to avoid template fatigue

## Accuracy/trust
- promise matches video
- no fabricated context
- assets and likenesses authorized

## Experiment
- candidate version labeled
- intended variable documented
- baseline defined
- measurement plan recorded
