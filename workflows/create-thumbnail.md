# Workflow: Create Thumbnail

## Inputs

Use any available combination of:

- video title
- video summary/script
- target audience
- channel style
- brand constraints
- reference images
- creator identity
- desired tone

## Procedure

### A. Strategic extraction

Write:

- core promise
- strongest emotion
- primary subject
- supporting element
- curiosity gap
- title message
- thumbnail message

### B. Concept sprint

Generate 8 concepts.

For each concept specify:

- one-sentence idea
- primary subject
- supporting element
- composition
- camera perspective
- emotional signal
- text hook, if any
- background treatment
- main curiosity mechanism

### C. Selection

Reject concepts that:

- require explanation to understand
- contain too many focal points
- depend on tiny details
- are visually generic
- duplicate the title
- become confusing on mobile

### D. Final production brief

Specify:

- canvas
- subject placement
- scale
- crop
- expression/pose
- object placement
- negative space
- color relationships
- lighting direction
- contrast hierarchy
- typography
- text placement
- depth
- background complexity
- platform-safe areas

### E. Generation prompt

The final image-generation prompt should explicitly describe:

1. subject
2. action/state
3. composition
4. camera
5. lighting
6. environment
7. depth
8. typography treatment when supported
9. visual hierarchy
10. realism/quality constraints

### F. Variants

Create 2–3 variants where each changes one major hypothesis:

- expression
- crop
- hook
- supporting object
- composition

Do not change everything simultaneously.
